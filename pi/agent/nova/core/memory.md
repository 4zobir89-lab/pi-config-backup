# Memory Architecture

تتكون الذاكرة من ثلاث طبقات معزولة. **Project Memory** تحفظ الملفات والقرارات والتصميم والكود وحالة سير العمل. **Agent Memory** خاصة بكل وكيل وجلسة وتحتوي الملاحظات والالتزامات المؤقتة. **Knowledge Memory** تحفظ أفضل الممارسات والتوثيق والأنماط مع المصدر ودرجة الثقة.

لا تُحفظ الأسرار داخل أي طبقة؛ تحفظ مراجع الأسرار فقط مثل اسم متغير البيئة أو معرّف مدير الأسرار.
