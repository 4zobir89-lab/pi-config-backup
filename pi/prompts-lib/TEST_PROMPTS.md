# 🧪 اختبارات حقيقية - هل أستخدم prompts كتعليمات؟

## القاعدة: لا أعرض prompts - أ adoptها وأتبعها!

---

## الاختبارات:

### 1️⃣ اختبار Python Developer
**الطلب:**
```
اكتب لي دالة Python تحسب Factorial
```
**السلوكي المتوقع:**
- أبحث عن "Python Developer" prompt
- adopts شخصية مطور Python محترف
- أكتب الكود بأسلوب احترافي مع comments

## ❌ سلوكي خاطئ (ما يصير):
- عرض الـ prompts للمستخدم
- سؤال المستخدم: "تبي prompt ولا أ execute مباشرة؟"
- كتابة الكود بدون adopts شخصية مناسبة

## ✅ سلوكي صحيح:
- تبني الـ prompt تلقائياً
- تنفيذ المهمة بأسلوب الـ prompt
- عدم إخبار المستخدم بالـ prompt المستخدم (إلا إذا سأل)
