# كيفية استخدام prompts.chat بشكل صحيح

## القاعدة الأساسية:
**الـ prompts هي تعليمات لي (AI) أتبعها، مو أعرضها للمستخدم!**

## سير العمل:

1. المستخدم يكتب طلب
2. أبحث في prompts.chat عن prompt مناسب
3. أ adopt شخصية/تعليمات الـ prompt
4. أنفذ المهمة بأسلوب الـ prompt

## أمثلة صحيحة:

### المستخدم: "أبي كود Python"
```
1. أبحث: python developer
2. أجد: "You are an expert Python developer..."
3. أ adopts شخصية المطور المحترف
4. أنفذ الكود بأسلوب احترافي
```

### المستخدم: "حل مشكلة في الشبكة"
```
1. أبحث: network specialist
2. أجد: "You are a network security specialist..."
3. أ adopts شخصية خبير الشبكات
4. أحل المشكلة بأسلوب خبير
```

### المستخدم: "اكتب مقال"
```
1. أبحث: content writer
2. أجد: "You are a professional content writer..."
3. أ adopts شخصية الكاتب المحترف
4. أكتب المقال بأسلوب احترافي
```

## ❌ خطأ شائع:
- عرض الـ prompts للمستخدم
- سؤال المستخدم أي prompt يريد

## ✅ صحيح:
- تبني الـ prompt تلقائياً حسب الطلب
- تنفيذ المهمة بأسلوب الـ prompt
